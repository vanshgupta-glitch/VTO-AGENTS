### Video-test loop — first real end-to-end run (dev store `ankurs-vto`, pw-gated)
Ran the harness against the **live widget** through `shopify app dev`. The loop works and surfaced a chain of real bugs — each fixed:
- **Harness `time.sleep` didn't pump Playwright's event loop** → all console events dumped at close (fake "60s stall"). Fixed with `wait_for_timeout` + condition-based wait (wait for segmenter-ready, then observe).
- **Capture never fired** for a pre-recorded clip (can't align a video to the on-screen oval) → added `?vtoForceCapture=1` test seam (CaptureController `bypassAlignment`).
- **THE big one — segmenter wasn't actually primary.** `segment()` sat *after* the contour pipeline's `blocked`/`no-specs` early-returns, so the "primary" detector only ran once the contour approximation had already applied removal. Moved it to run **every pass, before the gates** ([[primary-not-additive]] honored for real now).
- **Mask discarded on ROI dims drift** (ROI size fluctuates every pass) → resize the cached mask instead of dropping it.
- **Threshold too low** (0.22) → bare-face false positives. On-device data: bare face peaks P≤0.45, worn glasses ~0.98 → raised to **0.5**.
- Added a **console verdict mirror** (HUD pill was invisible to logs).

**Result (post-warmup):** clear → removes (74%) ✅, no_glasses → no removal (84%) ✅, **sunglasses → block/remove flicker (~43% block)** ⚠️ — the occlusion "remove-vs-block" decision is noisy (pre-existing; needs darkness thresholds + sticky-block hysteresis). Segmenter loads in ~16 s (single-thread WASM), inference ~150–280 ms. Code is uncommitted with temp `seg-dbg` diagnostics to strip before the (human) commit.
